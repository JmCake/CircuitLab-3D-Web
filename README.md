# CircuitLab-3D｜大学电路虚拟实验室

**[打开在线实验室](https://jmcake.github.io/CircuitLab-3D-Web/)**

面向大学电路教学的程序化三维实验台，提供八项实验、器材接线、仪器控制台、测量记录、CSV 导出和数据大屏。

本仓库仅存放网站构建产物，源码工程保存在独立的私有仓库。网站由源码主分支通过测试后自动更新，无需下载安装。

建议使用支持 WebGL 2 的现代桌面浏览器。实验记录保存在当前浏览器本地，可导出工程和 CSV 备份。交流目前限于单频阻性网络，示波器为教学模型。

当前发布版本与源码提交可查看 [version.json](https://jmcake.github.io/CircuitLab-3D-Web/version.json)。
